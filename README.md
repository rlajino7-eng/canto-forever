# Canto Forever

Primera versión funcional de la academia virtual de canto.

## Incluye

- Dashboard
- 60 clases estructuradas
- Modo clase
- Profesora hablada mediante SpeechSynthesis
- Biblioteca de ejercicios
- Entrenamiento auditivo con tonos generados por Web Audio API
- Metrónomo/temporizadores de práctica
- Grabación de voz desde el navegador
- Progreso
- Cuaderno
- Repertorio
- Persistencia local mediante localStorage
- Diseño responsive

## Ejecutar

No requiere servidor para la primera prueba.

Abre `index.html` en un navegador moderno.

Para micrófono, algunos navegadores exigen servir la página desde `localhost` o HTTPS.
